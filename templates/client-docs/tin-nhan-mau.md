# Tin nhắn mẫu (Zalo)

> Xưng "mình – bạn", ngắn, thân thiện. Thay phần trong `[ ]`. Không nhắc tới AI.

## 1. Mở đầu (khách nhắn lần đầu)

```
Chào [tên], mình là [X] bên Alpha Lab nè 👋
Bạn đang cần hỗ trợ phần nào: tạo khảo sát, xử lý data hay chạy SPSS?

Để mình xem nhanh và báo giá (miễn phí), bạn gửi giúp mình:
1. Tên đề tài + mô hình nghiên cứu
2. Bảng hỏi / file data (nếu có)
3. Yêu cầu của giảng viên (nếu có)
4. Deadline của bạn
```

## 2. Hỏi thêm khi chưa rõ

```
Cho mình hỏi thêm chút nha:
- Bài này là tiểu luận môn, NCKH hay khóa luận vậy bạn?
- Hiện bạn đã có data chưa, hay đang cần thu khảo sát?
- Giảng viên có bắt buộc kiểm định nào không (EFA, hồi quy, ANOVA…)?
```

## 3. Gửi đánh giá + báo giá

Dùng phần 6 của `templates/case/01_assessment.md`, rồi báo giá theo `bao-gia.md`.

## 4. Xác nhận đã nhận cọc

```
Mình nhận được cọc rồi nha, cảm ơn bạn 🙏
Mình bắt đầu từ hôm nay, dự kiến [ngày] gửi bạn [bước tiếp theo].
Có gì cần xác nhận mình nhắn bạn liền.
```

## 5. Checkpoint: xác nhận Analysis Plan (sau bước 2)

```
Mình gửi bạn kế hoạch phân tích nè, gồm các kiểm định sẽ chạy và tiêu chí đánh giá.
Bạn xem giúp mình, nếu giảng viên có yêu cầu gì khác thì báo mình trước khi chạy nha.
Bạn OK thì mình làm tiếp luôn.
```

## 6. Checkpoint: xác nhận số phiếu (sau bước 4)

```
Data làm sạch xong rồi nè. Từ [N gốc] phiếu, còn [N cuối] phiếu hợp lệ:
- [x] phiếu trùng
- [y] phiếu sai câu kiểm tra chú ý
- ...
Chi tiết trong file Cleaning Log. Bạn OK với [N cuối] phiếu thì mình chạy phân tích nha.
```

## 7. Báo trước kết quả chính (sau bước 5)

```
Mình chạy xong rồi, báo nhanh kết quả chính trước nha:
- Thang đo: [đạt / loại item nào]
- Giả thuyết được ủng hộ: [H1, H2…]
- Không được ủng hộ: [H…], cái này vẫn là kết quả hợp lệ, mình sẽ hướng dẫn bạn cách giải thích trong báo cáo.
Khoảng [thời gian] mình gửi đủ file + báo cáo giải thích.
```

## 8. Bàn giao

```
Gửi bạn hồ sơ đầy đủ nè 📦 [link Drive]
Bạn mở file README trước để biết từng file dùng làm gì nha.

Tóm tắt kết quả:
1. ...
2. ...

Chỗ nào chưa hiểu bạn cứ nhắn mình, hỗ trợ trong 30 ngày nha.
Phần còn lại [số]đ bạn chuyển giúp mình khi tiện nhé.
```

## 9. Xin feedback (sau khi khách nộp bài / bảo vệ)

```
Bài của bạn sao rồi? Hy vọng mọi thứ suôn sẻ 😊
Nếu tiện, bạn trả lời giúp mình 3 câu ngắn để bên mình làm tốt hơn nha: [link form]
```

## 10. Từ chối yêu cầu ngoài phạm vi

```
Phần này bên mình không hỗ trợ được bạn ơi, vì [sửa số liệu / thêm phiếu / viết hộ…]
có thể khiến bạn gặp rủi ro khi giảng viên kiểm tra.
Thay vào đó mình có thể [phương án hợp lệ], vẫn giải quyết được vấn đề [X] của bạn.
```

## 11. Nhắc khách gửi tài liệu (sau 2 ngày im lặng)

```
Hi [tên], bạn còn cần hỗ trợ phần [X] không nè?
Bạn gửi [tài liệu còn thiếu] là mình xem và báo giá luôn nha.
```
