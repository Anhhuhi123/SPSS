# SPSS: Alpha Lab

Dịch vụ thu thập, xử lý và phân tích số liệu SPSS cho sinh viên kinh tế.

| Đường dẫn | Nội dung |
|---|---|
| `index.html`, `brand/alpha-lab/` | Landing page (HTML/CSS/JS thuần), deploy thẳng lên Vercel |
| `PLAN.md` | Kế hoạch tổng thể |
| `CLAUDE.md` | Quy tắc làm việc cho Claude Code |
| `docs/` | Bảng giá, phạm vi dịch vụ, quy trình consulting, chuẩn phân tích, cây chọn kiểm định |
| `templates/case/` | Khung thư mục cho mỗi case (`case.yaml`, assessment, analysis plan, cleaning log, report) |
| `templates/client-docs/` | Tin nhắn mẫu, báo giá, README bàn giao, form feedback |
| `cases/` | Dữ liệu khách: **gitignore**, không commit |

Tài liệu nội bộ không được deploy (xem `.vercelignore`).
